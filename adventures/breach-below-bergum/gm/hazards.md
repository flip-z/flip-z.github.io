# Hazard Index
{: tabindex="-1" }

The PDF names four published hazards but does not reproduce their rules. Use their published statistics; do not improvise missing DCs or effects from the room summaries.

## Entombed Spirit {#entombed-spirit}

- **Location:** A2, cracked sarcophagus
- **Trigger:** Interaction with the damaged tomb, as defined by the published hazard
- **Detection / disable / effect / reset:** Use the published stat block
- **Adventure interaction:** The casket cover is AC 15, Hardness 5, and requires DC 18 Athletics to move
- **Source:** Named in the supplied PDF; exact published source link remains to be confirmed

## Hampering Web {#hampering-web}

- **Location:** A3, large northern funerary urn
- **Trigger:** A creature reaches into the urn
- **Detection / disable / effect / reset:** Use the published stat block
- **Follow-up:** A Spider Swarm emerges
- **Source:** Named in the supplied PDF; exact published source link remains to be confirmed

## Phantom Footsteps {#phantom-footsteps}

- **Location:** A5, immediately past the collapsed wall
- **Trigger:** The first character enters the hallway
- **Detection / disable / effect / reset:** Use the published stat block
- **Source:** Named in the supplied PDF; exact published source link remains to be confirmed

## Pit of Toil {#pit-of-toil}

- **Location:** A5, near the corner and skeleton
- **Trigger:** A character approaching without darkvision or a light source trips over the skeleton
- **Detection / disable / effect / reset:** Use the published stat block
- **Source:** Named in the supplied PDF; exact published source link remains to be confirmed

## Barrow Pulse {#barrow-pulse}

- **Location:** Grand Mausoleum
- **Trigger:** Activates after the Warning Pulse and Retainers awaken
- **Detection:** Scorched sightlines and clean column shadows make the line-of-effect behavior discoverable
- **Disable:** Ends when the Runelord is destroyed; the supplied custom stat block may provide additional methods
- **Routine:** Pulses from the casket, then from the Runelord; solid columns completely block it
- **Reset:** Does not reset after the Runelord is destroyed
- **Source:** Custom level-4 complex hazard; see the [Barrow Pulse reference]({{ '/adventures/breach-below-bergum/gm/bestiary/barrow-pulse/' | relative_url }})
